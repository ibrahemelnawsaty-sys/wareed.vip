# خطوات تعديل ملف `.env` على الاستضافة (Hostinger)

> `.env` ملف إعدادات يعيش **على السيرفر فقط** ولا يُرفع إلى Git إطلاقاً (فيه كلمات مرور).
> تعديله لا يحتاج أي رفع ملفات ولا نشر جديد — يسري مفعوله فور الحفظ ومسح الكاش.

---

## أولاً: احصل على كلمة مرور بريد `info@wareed.vip`

1. ادخل **hPanel** → **Emails** → **Email Accounts**.
2. اختر `info@wareed.vip` → **Change password** (إن لم تكن تحفظها).
3. اضبط كلمة مرور قوية واحتفظ بها عندك — **لا تكتبها في Git ولا ترسلها لأحد**.

---

## ثانياً: افتح `.env` وعدّله

1. **hPanel** → **Files** → **File Manager**.
2. ادخل مجلد المشروع: `public_html` (أو `domains/wareed.vip/public_html`).
3. الملف مخفي؛ فعّل **Settings ⚙ → Show hidden files (dotfiles)** حتى يظهر `.env`.
4. كليك يمين على `.env` → **Edit**.
5. ابحث عن الأسطر التي تبدأ بـ `MAIL_` واستبدلها بالكامل بهذه:

```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.hostinger.com
MAIL_PORT=465
MAIL_SCHEME=smtps
MAIL_USERNAME=info@wareed.vip
MAIL_PASSWORD=ضع_كلمة_المرور_هنا
MAIL_FROM_ADDRESS="info@wareed.vip"
MAIL_FROM_NAME="شركة وريد لتقنية المعلومات"
```

6. تأكّد أيضاً من هذين السطرين في نفس الملف (مهمّان للروابط الموقّعة في البريد):

```env
APP_URL=https://wareed.vip
APP_ENV=production
APP_DEBUG=false
```

7. **Save**.

### قواعد لا تُكسر عند التحرير
- لا مسافات حول علامة `=` — الصحيح `MAIL_PORT=465` لا `MAIL_PORT = 465`.
- لا تضع علامات اقتباس حول كلمة المرور **إلا** إذا كانت تحتوي مسافة أو `#`؛ عندها ضعها بين `"` مزدوجة.
- لا تحذف بقية أسطر الملف (`APP_KEY` تحديداً — حذفه يُعطّل الموقع بالكامل).
- سطر يبدأ بـ `#` = تعليق ومُهمَل.

---

## ثالثاً: امسح كاش الإعدادات (خطوة إلزامية)

Laravel يقرأ `.env` مرة واحدة ويخزّنه. بدون هذه الخطوة لن يرى التعديل.

- **من File Manager:** ادخل `bootstrap/cache/` واحذف الملف `config.php` إن وُجد.
- **أو من الطرفية** إن كان SSH متاحاً:
  ```bash
  cd ~/public_html && php artisan config:clear
  ```

---

## رابعاً: اختبر

1. افتح `https://wareed.vip/admin/quote-requests`.
2. اضغط زر **«اختبار البريد»** في أعلى الصفحة.
3. النتيجة تظهر مباشرة:
   - ✅ نجاح ⇐ ستصلك رسالة على بريد الاستقبال المضبوط في **إعدادات الموقع → البريد الإلكتروني**.
   - ❌ فشل ⇐ الرسالة تعرض **سبب الخطأ الحرفي من SMTP** (كلمة مرور خاطئة / منفذ مغلق / …).

### أخطاء شائعة ومعناها
| الرسالة | السبب | الحل |
|---|---|---|
| `Authentication failed` / `535` | كلمة المرور خاطئة | أعد ضبطها من hPanel → Emails |
| `Connection could not be established` | المنفذ 465 مغلق أو `MAIL_SCHEME` ناقص | تأكّد من `MAIL_PORT=465` و`MAIL_SCHEME=smtps` |
| البريد يعمل لكن لا يصل | يذهب إلى Spam | فعّل SPF/DKIM/DMARC — راجع `docs/خطة_ربط_البريد.md` §4 |
| لا يتغيّر شيء بعد التعديل | كاش الإعدادات | احذف `bootstrap/cache/config.php` |

---

## ملاحظة أمنية
كلمة مرور البريد وبيانات قاعدة البيانات تبقى **داخل `.env` على السيرفر فقط**.
لا تنسخها في رسالة، ولا في ملف داخل المستودع، ولا ترسلها لأي جهة — الكود لا يحتاج رؤيتها، يقرأها من الملف مباشرة.
