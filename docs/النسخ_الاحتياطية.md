# النسخ الاحتياطية — أخذها، تنزيلها، والرجوع إليها

> **الخلاصة في سطرين:** لوحة التحكم ← **النظام ← النسخ الاحتياطية** ← «خذ نسخة احتياطية الآن»
> ← **نزّل الملف إلى جهازك**. وللرجوع: الزرّ الأصفر «استرجاع» أمام النسخة المطلوبة.

---

## ما الذي تحفظه النسخة؟

| يدخل النسخة | لا يدخل النسخة |
|---|---|
| قاعدة البيانات كاملة: الطلبات، عروض الأسعار وسجلّ إصداراتها، العقود وبنودها وقرارات العملاء، الخدمات، الصفحات، المتاجر والمنتجات، الإعدادات، المستخدمون | ملف `.env` (فيه كلمات مرور البريد الإلكتروني وقاعدة البيانات) — مكانه الخادم وحده ولا يُنسخ ولا يُرفع لأي مكان |
| ملفات العملاء: متطلبات المشروع، النسخ الموقّعة من العقود، ختم الشركة | شيفرة المشروع و`vendor/` — محفوظة في Git، ونسخة الكود هي المستودع نفسه |
| صور المتاجر والمنتجات المرفوعة من اللوحة | الكاش والجلسات والطوابير — بيانات متطايرة لا معنى لاستعادتها |

كل نسخة ملف `.zip` واحد يحمل داخله:

- `manifest.json` — تاريخ النسخة وملاحظتها وعدد سجلّات كل جدول وعدد الملفات.
- `database/database.sqlite` — ملف قاعدة البيانات نفسه بأمانة تامة.
- `database/tables/*.json` — تفريغ كل جدول على حدة، نسخة احتياطية للنسخة الاحتياطية:
  تعمل حتى لو تغيّر محرّك قاعدة البيانات بين وقت أخذ النسخة ووقت استرجاعها.
- `storage/local/…` و`storage/public/…` — ملفات العملاء وصور الموقع.

## أخذ نسخة

### من اللوحة (الطريقة المعتادة)
**النظام ← النسخ الاحتياطية** ← اكتب سبب النسخة في الخانة (اختياري، مثل «قبل تعديل سجلّ
الإصدارات») ← **«خذ نسخة احتياطية الآن»**. تظهر النسخة في القائمة خلال ثوانٍ.

### من سطر الأوامر (إن كان SSH متاحاً)
```bash
cd ~/public_html
php artisan backup:run --note="قبل النشر"
php artisan backup:run --list          # عرض النسخ المحفوظة
```

### جدولة نسخة يومية تلقائية
hPanel ← **Advanced ← Cron Jobs ← Create** ← أمر يومي الساعة الثالثة فجراً:
```bash
cd ~/public_html && php artisan backup:run --note="نسخة يومية"
```

## نزّل النسخة إلى جهازك — الخطوة التي لا تُهمَل

النسخ تُحفظ في مجلّد خاصّ على الخادم (`storage/app/private/backups/`) لا يصله أحد من
الإنترنت، ويبقى منها أحدث **12** نسخة ثم تُحذف الأقدم تلقائياً.

**نسخة على الخادم وحده تضيع مع الخادم.** بعد كل نسخة مهمّة اضغط **«تنزيل»** واحفظ الملف
عندك (جهازك، أو Google Drive، أو قرص خارجي).

## الرجوع إلى نسخة

1. **النظام ← النسخ الاحتياطية** ← الزرّ الأصفر **«استرجاع»** أمام النسخة المطلوبة.
2. تظهر رسالة تأكيد تشرح ما سيحدث — اقرأها ثم أكّد.
3. يعود الموقع بالكامل إلى لحظة تلك النسخة: قاعدة البيانات وكل ملفات العملاء.

### ثلاث حقائق عن الاسترجاع
- **يُلغي كل ما بعده:** أي طلب أو عرض أو عقد أو ملف وصل بعد لحظة النسخة سيختفي.
- **له طريق عودة:** تُؤخذ **نسخة أمان تلقائية** قبل أن يمسّ الاسترجاع شيئاً، باسم يبدأ
  بالتاريخ وملاحظتها «نسخة أمان تلقائية قبل الاسترجاع». إن استرجعت النسخة الخطأ،
  استرجع نسخة الأمان وتعود الأمور كما كانت.
- **قد يطلب منك تسجيل الدخول من جديد:** جلسات الدخول جزء من قاعدة البيانات، فاسترجاع
  نسخة قديمة قد ينهي جلستك الحالية. سجّل الدخول وتابع.

## استرجاع على خادم جديد (لو فُقد الخادم كله)

1. ارفع شيفرة المشروع من Git إلى الخادم الجديد، وأنشئ ملف `.env` كما في
   [`خطوات_تعديل_env.md`](خطوات_تعديل_env.md).
2. ادخل لوحة التحكم ← **النظام ← النسخ الاحتياطية** ← قسم **«استرجاع من نسخة على جهازك»**
   ← اختر ملف النسخة التي نزّلتها سابقاً ← **«ارفع الملف»**.
3. تظهر النسخة في القائمة ← اضغط **«استرجاع»**.

> النسخة المرفوعة تُفحص قبل قبولها؛ الملف الذي ليس نسخة صالحة يُرفض ولا يُحفظ.
> الحدّ الأقصى لحجم الملف المرفوع 50 ميغابايت.

---

## ماذا تحفظ خارج هذا النظام؟

| الشيء | مكان حفظه |
|---|---|
| شيفرة المشروع | مستودع Git — كل دفعة نسخة بتاريخها |
| `.env` (كلمات المرور والمفاتيح) | احتفظ بنسخة منه في مدير كلمات مرور، **لا في Git ولا في النسخ الاحتياطية** |
| `APP_KEY` تحديداً | داخل `.env` — حذفه يُعطّل الموقع، فاحفظه معه |

---

## من يملك هذه الصفحة؟

صفحة النسخ الاحتياطية **لمدير النظام (`super_admin`) وحده** — لا يراها موظّف ولا مشرف عادي،
لأن زرّ الاسترجاع يكتب فوق كل بيانات الموقع.
